# H2 Plan 3: Native Kotlin Android App (Today+Add First) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the native Kotlin Android app that is the single daily surface for the Adaptive SR system: Today rating + Add first, then Library + Stats.

**Architecture:** Room is the single UI source of truth; Supabase PostgREST/RPC is the system of record reached only via repository + WorkManager; supabase-kt for Supabase, Retrofit for Raindrop REST only; optimistic rating with pendingSync outbox and serial flush; FCM data push triggers re-pull, local 8am ReminderWorker is the fallback.

**Tech Stack:** Kotlin 2.0, Compose BOM + Material3, Hilt 2.52, Room 2.6.1, WorkManager 2.9.0, Encrypted DataStore 1.1.1 (AES256-GCM via Tink), supabase-kt 3.0.4 (postgrest + gotrue), Retrofit 2.11.0 + OkHttp + Moshi, Firebase FCM 23.2, JUnit4 + Turbine 1.1.0 + Room testing + WorkManager testing, minSdk 28 targetSdk 34.

**Spec:** `docs/superpowers/specs/2026-09-03-h2-hybrid-android-app-design.md` (Sections 2-3 authoritative for this plan; Section 1 DDL/RPC contract consumed as-is)

## Global Constraints

- Single user, free-forever, no billing anywhere.
- Timezone `Asia/Kolkata`, digest bucketing `en-IN` — Stats/Sync display uses this, never device default silently.
- Android talks only to Supabase PostgREST/RPC — never to Sheets/Tasks directly; Retrofit touches Raindrop REST only.
- Room is UI truth, never PostgREST directly (Spec Section 2).
- Phone never inserts cards directly on Raindrop toggle-on — toggle-on enqueues insert deduped on `unique(raindrop_id)`; toggle-off never deletes the card (no-delete rule).
- All Supabase reads go Room-upsert; all writes go `pendingSync=1` then serial flush.
- Error mapping: `INVALID_RATING` drop + bug-log; `ALREADY_PROCESSED` clear flag; `RATE_LIMITED`/timeout keep queued + retry; `NOT_FOUND` drop + refresh; never silent-drop otherwise.
- Writes via RPC only (`process_review` etc.); reads may use direct PostgREST `GET /rest/v1/cards`.
- Envelope everywhere: `{success, data, errorCode, version:1}` with `INVALID_RATING | ALREADY_PROCESSED | RATE_LIMITED | NOT_FOUND`.
- Auth: no login screen — paste Supabase JWT + Raindrop token into Encrypted DataStore; keys `supabase_jwt`, `raindrop_token`, `fcm_token`.
- Notifications: FCM payload `{due_count}` never trusted — always re-query Room; local ReminderWorker daily 8am local is the no-FCM fallback; digest format `Daily Digest - N items (M overdue)`.
- Old GAS paths stay live as fallback; app must work fully offline (airplane-mode rate then queued then flush).

```kotlin
package com.adaptivesr.data
import androidx.datastore.core.DataStore
import androidx.datastore.preferences.core.*
import kotlinx.coroutines.flow.map
import javax.inject.Inject
import javax.inject.Singleton

val SUPABASE_JWT = stringPreferencesKey("supabase_jwt")
val RAINDROP_TOKEN = stringPreferencesKey("raindrop_token")
val FCM_TOKEN = stringPreferencesKey("fcm_token")

@Singleton
class TokenStore @Inject constructor(private val ds: DataStore<Preferences>) {
  val supabaseJwt = ds.data.map { it[SUPABASE_JWT] }
  val raindropToken = ds.data.map { it[RAINDROP_TOKEN] }
  val fcmToken = ds.data.map { it[FCM_TOKEN] }
  suspend fun setSupabaseJwt(v: String) { ds.updateData { it.toMutablePreferences().apply { set(SUPABASE_JWT, v) }.toPreferences() } }
  suspend fun setRaindropToken(v: String) { ds.updateData { it.toMutablePreferences().apply { set(RAINDROP_TOKEN, v) }.toPreferences() } }
  suspend fun setFcmToken(v: String) { ds.updateData { it.toMutablePreferences().apply { set(FCM_TOKEN, v) }.toPreferences() } }
}
```

`core/Sm2.kt`:

```kotlin
package com.adaptivesr.core
enum class Rating { MASTER, EASY, GOOD, HARD, RELEARN }
object Sm2 {
  fun preview(prev: Int, n: Int, rating: Rating): Int = when (rating) {
    Rating.MASTER -> 0
    Rating.RELEARN -> 1
    Rating.EASY -> if (n == 0) 4 else Math.round(prev * 2.5).toInt()
    Rating.GOOD -> if (n == 0) 2 else Math.round(prev * 2.0).toInt()
    Rating.HARD -> if (n == 0) 1 else Math.round(prev * 1.2).toInt()
  }.let { if (rating != Rating.MASTER && rating != Rating.RELEARN && n != 0) maxOf(it, 1) else it }
}
// Intentional divergence from SQL recorded here: spec SQL `sm2_next_interval(0, n>0, ...)`
// yields round(0*mult)=0, while preview() clamps to maxOf(it,1)=1. Preview is display-only;
// the server RPC is authoritative on flush, so a 0-vs-1 preview gap never persists.
```

```kotlin
package com.adaptivesr.data.local
import androidx.room.*
import kotlinx.coroutines.flow.Flow
@Dao
interface CardDao {
  @Query("SELECT * FROM cards WHERE suspended = 0 AND (dueAt IS NULL OR dueAt <= :now) ORDER BY dueAt ASC NULLS FIRST, id ASC")
  fun dueQueue(now: Long): Flow<List<CardEntity>>
  @Query("SELECT * FROM cards WHERE title LIKE '%' || :q || '%' OR link LIKE '%' || :q || '%' ORDER BY updatedAt DESC LIMIT 200")
  fun searchAll(q: String): Flow<List<CardEntity>>
  @Query("SELECT * FROM cards WHERE pendingSync = 1 ORDER BY dueAt ASC NULLS FIRST, id ASC")
  suspend fun pendingOrdered(): List<CardEntity>
  @Query("SELECT * FROM cards WHERE id = :id") suspend fun byId(id: String): CardEntity?
  @Query("SELECT * FROM cards WHERE raindropId = :id LIMIT 1") suspend fun byRaindrop(id: Long): CardEntity?
  @Insert(onConflict = OnConflictStrategy.REPLACE) suspend fun upsertAll(rows: List<CardEntity>)
  @Query("UPDATE cards SET pendingSync = :pending, lastError = :lastError WHERE id = :id")
  suspend fun markPending(id: String, pending: Int, lastError: String?)
  @Query("UPDATE cards SET pendingSync = 0, lastError = NULL, idempotencyKey = :key WHERE id = :id")
  suspend fun markFlushed(id: String, key: String)
```

```kotlin
suspend fun rateCard(id: String, rating: Rating) {
  val c = dao.byId(id) ?: return
  val key = UUID.randomUUID().toString()
  val next = Sm2.preview(c.intervalDays, c.reviewCount, rating)
  dao.upsertAll(listOf(c.copy(intervalDays = next, lastRating = rating.name, pendingSync = 1, idempotencyKey = key, lastReviewedAt = System.currentTimeMillis(), status = if (rating == Rating.MASTER) "MASTERED" else c.status, suspended = if (rating == Rating.MASTER) true else c.suspended)))
}
suspend fun flushPending() {
  for (c in dao.pendingOrdered()) {
    when (val r = remote.flushReview(c.id, Rating.valueOf(c.lastRating ?: "GOOD"), c.idempotencyKey ?: UUID.randomUUID().toString())) {
      is ApiResult.Ok -> dao.markFlushed(c.id, c.idempotencyKey ?: "")
      is ApiResult.Err -> when (r.code) {
        ErrorCode.ALREADY_PROCESSED -> dao.markFlushed(c.id, c.idempotencyKey ?: "")
        ErrorCode.INVALID_RATING, ErrorCode.NOT_FOUND -> { dao.markPending(c.id, 0, r.code.name); pullDue() }
        else -> dao.markPending(c.id, 1, r.code.name)
      }
    }
  }
  meta.put(SyncMeta("lastFlush", System.currentTimeMillis().toString()))
}
```

```kotlin
override suspend fun enqueueRaindropIfAbsent(item: RaindropItemRef) {
  if (dao.byRaindrop(item.itemId) != null) return
  // Outbox row keyed on the UNIQUE(raindropId) constraint: if J4 inserts the same
  // raindrop concurrently, Room REPLACE on conflict keeps one row and the server-side
  // unique(raindrop_id) is the final dedupe authority on flush (conflict → ALREADY_PROCESSED clears flag).
  dao.upsertAll(listOf(CardEntity(id = UUID.randomUUID().toString(), title = item.title, link = item.link, source = "RAINDROP", raindropId = item.itemId, pendingSync = 1, idempotencyKey = UUID.randomUUID().toString())))
}
override suspend fun setRaindropEnabled(item: RaindropItemRef, enabled: Boolean) {
  if (enabled) enqueueRaindropIfAbsent(item)
  // toggle-off: intentionally no delete, card stays with pendingSync unchanged
  when (val r = remote.setSrTag(item.itemId, enabled)) {
    is ApiResult.Ok -> Unit
    is ApiResult.Err -> dao.byRaindrop(item.itemId)?.let { dao.markPending(it.id, it.pendingSync, r.code.name) }
  }
}
```
